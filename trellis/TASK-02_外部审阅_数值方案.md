# 尿意档位重设计 · 完整方案（供外部 AI 审阅）

## 项目背景

这是一个 SillyTavern（酒馆）生物追踪插件（biotracker），用数值模拟角色从非孕到孕期到产后的代谢状态。尿意是其中一个数值系统，需要一套档位边界和数值表，服务于角色扮演叙事。

设计目标：数值要服务于叙事体感，不是照搬医学数据，但方向参考真实生理。孕期尿频、尿不尽、失禁、排不出来等现象都要在数值上有体现。

---

## 六档结构

值从 0 到上限，分六档：无 → 低 → 中 → 高 → 满 → 爆

| 档 | 体感 |
|---|---|
| 无 | 空的，没有。膀胱排空，不胀不坠，刚去过，可以正常做任何事 |
| 低 | 有一点了。不是想尿，是「知道有」。坐一会儿能感觉到下面沉了一团。不急，不去也行，可以忘掉 |
| 中 | 明显想去了。坐不住、换腿、算时间。还能忍但注意力开始被扯。走路的步子收了 |
| 高 | 很急。不想去了，是真的急。做事会顿、说话会停。并着腿、小腹发紧 |
| 满 | 该去了，再不去要出事。胀、沉、发硬，坐不直，步子碎、腰不敢直 |
| 爆 | 收不住了。括约肌在打颤，一个咳嗽一个喷嚏就可能出来。不是在忍，是在跟身体抢时间。爆档 ≠ 已失禁——到顶了随时会崩，但还没崩那一刻更难受 |

### 档内渐变通则

值越靠近下一档下界，感受越往下一档靠。所有档统一规则，不写死哪一档特殊。AI 读到「值 + 档位 + 百分比」自己判断在档内的位置。

## 阶段链

非孕 → 孕早期 → 孕中期 → 孕晚期 → 临产期 → 自然逾期 / 延产 → 产后

- **临产期**：36-40 周，数值定位在孕晚期和自然逾期之间
- **自然逾期**（世界书 26 条）：40 周后未生，衰退层在走——羊水减少、胎动减弱、胎脂减少。压迫更直接（缓冲少了），但冲击减弱
- **延产**（世界书 27 条）：有外力把孕期按住（药、诅咒、术式、体质等），发育继续——羊水不减、胎动不弱、胎儿继续长。各项均比自然逾期更重
- **第二产程**单独处理，不参与正常涨落，值恒高，排一点又满
- **入盆**是附加状态，不是独立阶段。深度 0→1 连续，叠在孕晚期/临产期/自然逾期/延产上

## 数值设计原则

1. **满档和余量单向往下**，孕期不走回头路
2. **前松后紧**：无档最宽（没感觉的区间长），低中档中等，高满档窄（越急每一点增量都明显），爆档宽度 = 余量
3. **排完落档**：排完尿的落点（地板 + 残值）要落在该阶段对应的档位上，不是归零
   - 非孕排完落无档、孕中期落低档、孕晚期落中档、临产期落中档偏上、自然逾期/延产落高档、产后落低档偏上
4. **入盆修正量随基础阶段递增**：越往后胎头越大、压迫越重，同样的入盆深度效果越狠
5. **临产期及以上入盆满深后爆档消失**（到满即顶，没有挣扎区）
6. **三条出口终态不同**：排尿有底（落在对应档）、漏尿泄压（减几滴到一小股）、失禁真的空了（掉到很低甚至零，但地板很快推回来）
7. **正常排尿 vs 失禁**：正常排尿排不干净（有地板），孕期值从来降不到零；失禁是真的空了，但地板很快推回来

### 各字段含义

- **满档**：六档中「满」这档的上界，也是「爆」的下界。到这个值就是「该去了再不去要出事」
- **上限**：值的硬天花板，对应「真崩」（失禁）
- **余量**：满档到上限的距离，即「憋耐挣扎区」。非孕50点能忍很久，入盆后只有3点几乎立刻崩
- **地板**：排不掉的压迫感（胎头/子宫压着膀胱底），不是尿，怎么排都减不掉。排完后值不会低于地板
- **残值**：没排干净的尿，能靠双次排尿清掉
- **排完值**：排完尿后的落点 = 地板 + 残值

### 入盆满深修正量（递增，越往后越狠）

| 基础阶段 | 地板Δ | 满档Δ | 残值Δ |
|---|---|---|---|
| 孕晚期 | +8 | -8 | +0 |
| 临产期 | +12 | -10 | +0 |
| 自然逾期 | +14 | -12 | +2 |
| 延产 | +16 | -14 | +4 |

- 上限 = 满深满档 + 3（余量统一压到3）
- 深度 0→1 之间线性插值
- 临产期及以上满深后爆档消失

### 余量递减线

### 满档递减线

100 → 88 → 76 → 60 → 56 → 52 → 48 → 产后 72

## 孕早期涨速倍率

孕早期有额外涨速倍率 1.3×（HCG 导致膀胱敏感 + 盆腔内压迫）。孕中期回落到 1.0。

## 排不出来检定

- 全孕期覆盖（孕周 keyframe 曲线 + 入盆加成）
- 冷却 20 分钟，成功失败都进冷却
- 断断续续打七折（只放大残值部分）
- 姿势抵扣（抬臀、托腹）

---

## 待定项

1. **第二产程独立数值**：不参与涨落，值恒高，排一点又满
2. **失禁掉到的具体值**：现在用 urge×0.45，可能要改成更低（让失禁比正常排空更狠，真的空了）
3. **多胎加成表**：不是乘积，是结构性差异（地板直接高一档、余量更薄、排不出来概率更高）
4. **日常排尿触发线**：`applyRoutineUrineVoid` 目前在越过满档时触发自动排尿，但满档 = "该去了再不去要出事"，作为日常排尿触发太晚了。正常成年女性一天小便 6-8 次，触发线应该在哪个档？这涉及涨速和趟数的配合，待定。
5. **涨速基数**：目前非孕每小时涨 2 点（基数 `(1+fetalEnergyDrain)×2`），即使加上喝水刺激和睡眠转尿，一天只够排 1-2 次。但提高基数会导致孕期趟数爆炸。需要拆分非孕涨速和孕期涨速，或者调整 URINE_STAGE_RATE。

## 现有代码中的加减值体系（供参考）

### 每小时自然涨尿
- 基数：`(1 + fetalEnergyDrain) × 2 × passedHours`
- fetalEnergyDrain = 孕周/40（单胎正常体质）
- 再乘 URINE_STAGE_RATE（孕早期1.5、孕中期2、孕晚期3、入盆4）
- 进 addMetabolismValue，按档位权重加权（base 全1、stimulus 分档）

### 剧情刺激
- AI 传 urine 值：轻5/中10/强20
- 进 addMetabolismValue，按 stimulus 权重加权（无0.5、低1、中1、高1.5、满2、爆2）

### 睡眠转尿
- 睡眠体力回复量 × 0.2 转成尿意

### 各阶段每小时涨速（当前代码）

|---|---|---|---|---|
