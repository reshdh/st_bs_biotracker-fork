# 尿意漏表

漏是触发，不是每时每刻扣点。先看当前阶段开到哪一等，再看当前档 + 动作落在哪一等，最后按那一等减值。

姿势加压不算。湿的描写和扣点不必成正比。

---

## 一、各等减值

| 等 | 外面 | 减 | 档位 |
|---|---|---|---|
| 无 | 不湿 | 0 | 不动 |
| 渗 | 微湿，别人未必看得出 | −1～3 | 不换档 |
| 一小股 | 内裤明显湿一块 | −4～8 | 最多掉半档 |
| 一股 | 湿一片，短时间控制不住 | −8～15 | 可掉一档，到不了排完值 |
| 失禁 | 收不住，真的空 | 落到 min(0.20×满档, 0.35×地板) | 随后地板回推 |

孕晚 / 入盆 / 临产 / 延产：一小股取 −6～8，一股取 −12～15。  
非孕 / 孕早 / 孕中：取区间低到中。  
不要再乘倍率。渗始终 −1～3。

---

## 二、阶段：从哪一档开始允许哪一等

没开到的那一等，动作再大也只落到已打开的最高等。非孕爆档可以渗，但不轻易一股。

| 阶段 | 开渗 | 开一小股 | 开一股 | 开失禁 |
|---|---|---|---|---|
| 非孕 | 满末～爆（约 95+） | 爆中后段 | 接近上限 | 顶上限 |
| 孕早期 | 满 | 爆 | 爆末 | 上限附近 |
| 孕中期 | 高上 | 满 | 满末～爆 | 爆 |
| 孕晚未入盆 | 高 | 高上～满 | 满 | 满～爆 |
| 临产未入盆 | 高下界 | 高 | 满 | 满 |
| 孕晚入盆 | 高（去完就在） | 高 | 满 | 满 |
| 临产入盆 | 高顶 | 高顶～满 | 满 | 满 |
| 自然逾期未入盆 | 高 | 满 | 满 | 满～爆（钝） |
| 自然逾期入盆 | 满（去完就在） | 满 | 满 | 满 |
| 延产未入盆 | 高 | 高上 | 满 | 满 |
| 延产入盆 | 顶上就开 | 顶上 | 顶上 | 满 / 顶 |
| 产后 | 高 | 满 | 爆 | 爆 |

读法：非孕只有进 100～150 才认真检漏，且多半是渗、能夹回去。临产高档就开始溢。延产入盆去完还在顶上，动作很容易到一股或失禁。

---

## 三、动作 × 当前档 → 先判哪一等

这张表给出「倾向结果」，再和第二节取低：阶段还没开到的等，降一等。

| 当前档 | 咳 / 笑 / 喷嚏 | 轻跳、猛站起 | 跑、高潮、密宫缩 |
|---|---|---|---|
| 无 / 低 | 无 | 无 | 无或渗 |
| 中 | 无 | 无或渗 | 渗 |
| 高 | 渗 | 一小股 | 一股 |
| 满 | 一小股 | 一股 | 一股或失禁 |
| 爆 | 一小股或一股 | 一股或失禁 | 失禁 |

例：

- 非孕 120（爆）、咳嗽 → 表倾向「一小股或一股」，但非孕尚未开一小股到爆中后段、一股要接近上限 → 判**渗**，−1～3，能夹住。
- 非孕 145（接近上限）、跳 → 开了一小股，一股刚开门 → **一小股**，−4～6。
- 孕晚未入盆、高档、笑 → 已开渗，未开一小股 → **渗**，−1～3。
- 孕晚未入盆、满档、跳 → 已开一股 → **一股**，取高端 −12～15。
- 临产入盆、满档、高潮 → 开到失禁 → **一股或失禁**。
- 延产入盆、顶上、咳 → 顶上就开大漏 → **一小股**，取高端。

---

## 四、结算顺序

1. 看阶段开到哪一等  
2. 看当前档 + 动作的倾向等  
3. 两头取更低的那一等  
4. 按那一等扣点，孕晚及以后大漏取区间高端  
5. 扣完不得低于地板；失禁例外，先落到失禁落点，再由地板回推  
6. 已湿的衣服再渗，外面可以仍写湿，里面只扣渗的点  

高潮不走加，只走本表。
