# 尿意档位 · 终表

六档体感全程通用，吃喝只改变涨速，不改变档位含义。

| 档 | 体感 |
|---|---|
| 无 | 空的，刚去过，不胀不坠 |
| 低 | 知道有一点，不急，能忘掉 |
| 中 | 明显想去，还能忍，注意力开始被扯 |
| 高 | 真的急，做事会顿，并腿、小腹紧 |
| 满 | 该去了，再不去要出事 |
| 爆 | 收不住，还没崩，但随时会崩 |

自然产量（点/小时，不含吃喝）：非孕 12 · 孕早 15 · 孕中 14 · 孕晚 15 · 临产 / 逾期 16 · 延产 16 · 产后 13。睡眠按醒时 ×0.65。

「又想去」尺子：非孕 / 孕早看到中档下界；其余看到高档下界。排完已在高 / 满，则记为「去完就想」。临产起高档就可以渗，不用等爆。

日常间隔 = 同一条数轴 + 正常吃饭喝水，只加快走档，不改边界。

## 三、落地规则

1. 排完值 = 地板 + 残值，且必须 ≤ 上限；地板必须 < 满档。
2. 日常自动排触发在「又想去」那条线，不要等满档。满档只负责危急叙事和失禁检定。
3. 三条出口：正常排 → 落到排完值；漏尿 → 减 3～8 点；失禁 → 落到 `min(0.20×满档, 0.35×地板)`，再由地板回推。
4. 第二产程不进上表。锁定在当前满档附近，排一次减 8～12 点，10 分钟回到锁定值。
5. 孕早期产量 ×1.3 已写进 15 点/小时，不要再乘 fetalEnergyDrain 或旧的 1.5/2/3/4 阶段倍率。
6. 入盆只改容量和落点，不改产量。
