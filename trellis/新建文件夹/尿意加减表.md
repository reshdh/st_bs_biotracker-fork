# 尿意加减表

配套《尿意档位 · 终表》。姿势加压不算。时间自然涨已写在产量里，本表只列额外加减。

数字是一次事件的区间。无 / 低取低端，高 / 满 / 爆取高端。孕晚以后装不下，喝水类优先取高端。

一场里同类只结算一次：冰饮、高潮、宫缩不要在同一分钟各加一次满额。

---

## 加

| 类 | 算什么 | 一次加 | 怎么用 |
|---|---|---|---|
| 喝 · 小 | 几口、润一下 | +3～6 | 课间抿两口 |
| 喝 · 中 | 一杯常温或热的水 / 奶 | +8～14 | 日常主力 |
| 喝 · 大 | 大杯、连续喝、一碗汤 | +15～22 | 一顿带汤、灌水 |
| 喝 · 冰 | 冰水、冰饮、冰汽水 | 先按杯型加，再 +3～6 | 冷刺激，不是又造了一杯 |
| 利尿 | 咖啡、浓茶、酒 | 先按杯型加，再 +4～8 | 真的多造尿 |
| 吃 · 干 | 普通一餐、汤很少 | +2～5 | 可并进「喝」，不必每口加 |
| 睡 | 整晚 | 按睡眠产量走；孕晚起按醒时 ×0.8～1.0 | 不要和体力转尿再叠太狠 |
| 受凉 | 空调、雨淋、手脚冰，没喝东西 | +3～6 | 只有刺激，没有容量 |
| 强冷 | 冻得很狠、湿冷风 | +8～12 | 少用；不要和「受凉」叠 |
| 刺激 · 轻 | 听见水、紧张、胎动顶一下 | +3～6 | 一场一次 |
| 刺激 · 中 | 宫缩初起、被压到肚子、憋很久突然意识到 | +8～12 | 一场一次 |
| 刺激 · 强 | 密宫缩、惊吓 | +14～20 | 少用 |
| 性 · 动情 | 吻、磨、充血 | +3～8 | 一场一次，不加每分钟 |
| 性 · 加压 | 插入、压腹、顶深处 | +6～12 | 一段一次，不要每一记 |
| 性 · 高潮 | 不加值 | 0 | 改走漏检定 |

### 冰和冷怎么叠

| 情况 | 算法 | 例 |
|---|---|---|
| 一小口冰水 | 喝 · 小 + 冰 | +3～6，再 +3～6，取低端即可，大约 +6～10 |
| 一杯冰水 / 冰奶茶 | 喝 · 中 + 冰 | +8～14，再 +3～6 |
| 大杯冰饮 / 冰汽水 | 喝 · 大 + 冰 | +15～22，再 +3～6 |
| 冰咖啡、冰酒 | 杯型 + 冰 + 利尿 | 杯型后先 +3～6（冰），再 +4～8（利尿） |
| 只是空调、没喝 | 受凉 | +3～6 |
| 湿冷冻狠、没喝 | 强冷 | +8～12 |
| 边受凉边喝冰 | 只走喝 · 冰，不要再加受凉 | 冷只算一次 |

冰不是利尿。咖啡茶酒才多造尿；冰是膀胱被激一下。当前已在中档以上，冰那 +3～6 更偏向把体感抬一截，人不一定立刻满，但会突然很想去。

碳酸并进杯型高端，不要再开第三层。

---

## 减

| 类 | 外面看着 | 减多少 | 落点规则 |
|---|---|---|---|
| 正常排 | 去了厕所 | 降到排完值 | 地板 + 残值 |
| 排不出来 | 去了但几乎没出来 | 只减残值的 20～30% | 仍在原档附近 |
| 渗 | 微湿，别人未必看得出 | −1～3 | 不换档，该急还急 |
| 一小股 | 内裤明显湿一块 | −4～8 | 最多掉半档 |
| 一股 | 湿一片，短时间控制不住 | −8～15 | 可掉一档，到不了排完值 |
| 失禁 | 收不住，真的空 | 落到 min(0.20×满档, 0.35×地板) | 随后地板回推 |

湿的描写和扣点不必成正比。裤子已经湿了，再渗一次外面还是湿，里面可能只少 1～2 点。

---

## 漏：动作 × 当前档

动作只负责触发，当前档决定这次是渗还是一股。不要写死「咳嗽 = −2」。

| 当前档 | 咳 / 笑 / 喷嚏 | 轻跳、猛站起 | 跑、高潮、密宫缩 |
|---|---|---|---|
| 无 / 低 | 无 | 无或渗 | 渗 |
| 中 | 无或渗 | 渗 | 一小股 |
| 高 | 渗 | 一小股 | 一股 |
| 满 | 一小股 | 一股 | 一股或失禁 |
| 爆 | 一小股或一股 | 一股或失禁 | 失禁 |

阶段偏移：

- 孕晚未入盆：往右偏半格
- 入盆 / 临产 / 延产：再往右偏半格
- 自然逾期入盆：更容易渗，但冲击弱于延产

高潮默认走漏，不走加。已在高档以上，至少「一小股」；满 / 爆或入盆满深，按「一股」或失禁。

---

## 和档位终表的衔接

- 日常自动排看「又想去」，不要等满档
- 本表的加，只是让人更早碰到那条线
- 临产起高档就可以渗
- 逾期入盆、延产入盆满深后，日常自动排停用，减只走漏 / 失禁
- 第二产程不走本表的加，排一点十分钟左右回到锁定值
