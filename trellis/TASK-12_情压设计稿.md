## 一、现状

情压现在和体力改名前的「活力」一个毛病：`base.psyStress`（0~200）只有一个人工入口（`options.psyStress`），没有自动变化、没有衰减、没有回复。模型是它唯一的手，而模型手上没有说明书。

已有的读点（散落在各处，口径不一）：

| 位置 | 现在干什么 |
|---|---|
| `vitality_config.js` `SOFT_CAP_PSY_PRESSURE_START=120` | 情压 >120 压体力软顶（最多 12%） |
| `tools.js:2157` `getVitalityPressureMultiplier` | 情压 >140 宫压增速 ×0.7 |
| `tools.js:3892` 衍生代谢 flux 增速 | 情压偏离 100 越远，flux 涨速越快（0.5~1.5 倍） |
| `tools.js:5869` 胎方位安抚成功率 | `success = random >= psyStress/200`——情压越高越安抚不了 |
| `tools.js:6089` 假孕触发 | 情压 ≥100 + 性欲超基线 32 + 有伴侣 → 假孕 |
| `tools.js:6029` 经期波动 | psyStressLevel 6/7 加经期不规律度 |
| `tools.js:5123` 产痛 | psyStressLevel 偏离 4 加产痛 |

问题：
- **没有自动变化**——事件加的那一笔永远停在值上，跟体力改名前一个毛病（跳绳那次两个月后还在）。
- **读点口径不一**——有的读绝对值（≥100/≥120/≥140），有的读偏离 100 的量，有的读 level 不读值。
- **没有回复**——情压只涨不落，或只靠模型手动减，于是角色永远在高情压或永远不变。

## 二、定位

情压是**波动量**，不是存量资源条。跟宫压同款：事件加的那一笔会回落，停下来就缓解。

与体力（**还能撑多少**）分界：体力是「身体还剩多少」，情压是「心理被折腾到什么程度」。两本账不混——情压高不直接扣体力，它通过软顶间接压体力（已接线）。

承载三个效果：

1. **事件有后果**——恐惧、疼痛、冲突、被威胁会把情压推上去；安抚、休息、安全环境会拉回来。
2. **状态有载体**——长期高压的底色（焦虑、敏感、易崩溃）不只是当下演出。
3. **联动有出口**——情压高 → 软顶降（已接）→ 体力回不来；宫压增速打折（已接）→ 产程被拖；假孕触发（已接）；flux 涨速（已接）。

## 三、结构（三层，照体力同款）

| 层 | 是什么 | 规矩 |
|---|---|---|
| 体质上限（`PSY_STRESS_CAPS[psyStressLevel]`） | 天赋，她是谁 | **谁都不动**，1~7 对应 20/50/80/110/140/170/200 |
| 基线 | 这个人日常停在哪儿 | level 1~7 基线 = 上限 ×0.15~0.25（越敏感基线越低，平常时也闲不住但不会高压） |
| 当前值 | 此刻被折腾到什么程度 | 0~体质上限，**浮点存储**、显示取整 |

**基线核心规矩：事件加值往基线回落，不往 0 落。** 情压高停下来就缓解，但不会到 0——敏感的人平时也有一点底噪。没有这条，情压事件会被回落抹掉。

跟体力软顶是镜像：体力是天花板压低（回不到满），情压是基线抬高（落不到 0）。

## 四、涨的那一侧

### 4.1 底噪

**0.5/h，全程无条件**——「活着就在想事」。睡中也涨（由回复侧拉平），跟体力底噪同款。
敏感体质（level 5~7）底噪更高：0.8/1.2/1.5/h。

### 4.2 事件推量（三档）

| 程度 | 加量 | 典型场景 |
|---|---|---|
| 轻 | 3~8 | 被催促、小摩擦、走夜路有点怕 |
| 中 | 8~20 | 被骂、疼痛（痛经级）、目睹冲突、被威胁 |
| 强 | 20~35 | 剧烈疼痛（产痛级）、被袭击、恐惧到发抖、极端羞辱 |

规则照乳意同款：同档相加、超了按上一档算且封在那一档的顶。

### 4.3 孕期阶段倍率（叠在事件推量上）

情压是心理量，孕期激素放大情绪反应是实事。

| 阶段 | 倍率 | 理由 |
|---|---|---|
| 非孕 | ×1.0 | 基线 |
| 孕早期 | ×1.3 | 激素波动最大、情绪不稳 |
| 孕中期 | ×1.0 | 平稳期 |
| 孕晚期 | ×1.2 | 不适累积、对临产的恐惧 |
| 临产/逾期 | ×1.4 | 真的在来了 |
| 产兆前驱/产程 | ×1.5 | 疼痛＋恐惧到顶 |
| 产后 | ×1.3 | 产后抑郁风险窗口 |

倍率只乘事件推量，不乘底噪——底噪是性格特质，不随孕期变。

### 4.4 疼痛联动

产痛（`tools.js:5123` 已算）推情压：疼痛值 ×0.1 转成情压加量。
这条让「疼到崩溃」自动成立——疼痛不只是扣体力，也推情压，情压高又压软顶，环收敛（情压有回落兜底）。

## 五、落的那一侧

### 5.1 回落

**8/h 往基线回落**（照宫压 `PRESSURE_DECAY_PER_HOUR` 同款）。
停下那件事一两小时就缓过来，但长期持续的高压环境（被关着、被威胁着）会稳定停在高位——因为底噪在涨、回落抵不过。

### 5.2 安抚事件（减量）

| 程度 | 减量 | 典型场景 |
|---|---|---|
| 轻 | 3~8 | 被安慰几句、歇了一会儿 |
| 中 | 8~15 | 有人陪着、安全了、痛过了 |
| 强 | 15~25 | 长时间安抚、彻底安全、大哭一场发泄完 |

### 5.3 睡觉清情压

睡觉每小时清情压 ×0.5（底噪涨的一半）——睡一觉好一半。
但入盆深睡不实，打折同体力（×0.8）。

## 六、档位（五档，照体力同款但方向相同）

情压跟体力不同：都是值越高越难受，跟尿意便意同向。按占体质上限百分比分档：

| 档 | 边界 | 表现 |
|---|---|---|
| 平稳 | ≤ 基线 | 没什么情绪波动，该干嘛干嘛 |
| 紧绷 | 基线 → 50% | 有点不安，但压得住，问就是「没事」 |
| 焦躁 | 50% → 75% | 坐不住、反复确认、说话变快或变少、易怒 |
| 崩溃 | 75% → 90% | 控制不住了——哭、抖、说不成句、或反而僵住 |
| 断裂 | > 90% | 意识断片、解离、不认识人、或完全木僵 |

**关键口径：档位是「此刻被压到什么程度」，不是「她是什么样的人」。** 同一个 40%，安全环境里看不出来，被威胁着就现形。

## 七、联动（全部单向或收敛）

| 联动 | 方向 | 约束 |
|---|---|---|
| 情压高 → 软顶降 | 单向 | 已接（`SOFT_CAP_PSY_PRESSURE_START=120`） |
| 情压 >140 → 宫压增速 ×0.7 | 单向 | 已接（`getVitalityPressureMultiplier`） |
| 情压偏离 100 → flux 涨速 | 单向 | 已接（`tools.js:3892`） |
| 情压 ≥100 → 假孕触发条件之一 | 单向 | 已接 |
| 情压高 → 安抚胎方位成功率低 | 单向 | 已接（`psyStress/200`） |
| 产痛 → 情压涨 | 单向 | **待接**（§4.4，疼痛值 ×0.1） |
| 情压高 → 性欲慢性助长 | 单向 | **归 TASK-05**（急抑慢抬）——情压高压性欲底噪？还是只压软顶间接影响？待拍 |
| 体力耗竭 → 情压涨 | 单向 | **待接**——身体撑不住时心理也撑不住。量级小（体力 <30% 时 +1/h） |

**不做的联动**：
- 情压 → 尿意/便意/乳意（代谢键是生理过程，不跟心理混账）
- 情压 → 体力直接扣（走软顶，不 double-dip）
- 性欲 → 情压（性欲高不推情压——那是好事不是压力）

## 八、与现有读点的对齐

现有读点口径不一的问题，落码时统一：

| 读点 | 现口径 | 统一为 |
|---|---|---|
| 软顶压 | >120 起 | 不改——120 是上限 200 的 60%，对应「焦躁」档上沿，合理 |
| 宫压打折 | >140 | 不改——140 是 level 5 上限，对应「崩溃」档入口，合理 |
| flux 涨速 | 偏离 100 | **改**：读「高出基线多少」，不读绝对值——基线会动 |
| 假孕触发 | ≥100 | **改**：读「高出基线 50」——同宫压/性欲同法 |
| 胎方位成功率 | psyStress/200 | 不改——绝对值概率语义合理 |

## 十、验证

1. 跑七天日常：情压稳定在基线附近（底噪 vs 回落平衡）。
2. 事件推上去后 2~3 小时回落到基线。
3. 长期高压环境（持续事件推量）会稳定停在高位。
4. 软顶联动：情压 >120 时体力软顶可见下降。
5. 宫压打折：情压 >140 时产程倒计时变慢。
6. 环收敛：连推七天不转飞（底噪 vs 回落 vs 软顶兜底）。
