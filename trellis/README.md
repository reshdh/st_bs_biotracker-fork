## 已知的横向坑（每个任务都要看一眼）

1. **线值只能有一份。** 面板（`index.js`）与引擎（`tools.js`）必须调同一个函数取线。
   乳意那次就是容量在两边各算一次，孕早期百分比对不上。
2. **`node --test tests/` 这台机器上一定报错**，必须写成 `node --test "tests/*.test.js"`。
3. **新持久状态要进序列化。** `METABOLISM_PATCH_KEYS` 现在只覆盖八个代谢键，
   任何新增的计时器、冷却、深度值都得单独进去，否则存档一读就丢。
4. **删函数要连带删 `tracker_prompt_context.js` 里的说明句。**
   只删函数不删说明，模型会自己编读数 —— 乳意那次踩过。
5. **判据是看图，不是自造指标**（子宫壳那三个任务）。自己编的测量数经常是假的。
6. **删 `blockage` 时别碰乳腺那套。** `advanceMilkBlockage` /
   `relieveMilkBlockage` / `milk.duct` / `milk.blockHours` 是乳意四档设计的一部分，
   跟孕期三签同名不同物。搜 `blockage` 一律删会把它带走。
7. **提示词总量有预算。** 说明层分两档：**常驻**（字段一句话，如「体力 87/125，吃力期」）
   与**按需**（档位演出词，状态变化时才推）。食物表、刺激来源表这类**给例子不给全表**，
   模型照量级自行判断。全做完后做一次提示词审计。→ **已立卡 [TASK-13](TASK-13_提示词瘦身与触发保证.md)**
   （审计先查到一条要命的：七个报数入口只住在工具描述里，是唯一真源，按字符数砍会静默砍掉体力报数）。
8. **时间粒度不变性是通用回归。** 每加一张按天／按小时的表，「一次推 8h ≡ 八次推 1h」
   必须成立；长距离结算一律闭式计算，不许逐分钟循环。
9. **列表型状态必须带过期清扫。** `{source, amount, expiresAt}` 偏移列表、急性状态、
   窜稀计时器——长会话存档里不许堆死条目。
10. **存档迁移要能退役。** 各任务加的迁移段攒多了要删最老的；一套标准老档 fixture
    放 `tests/fixtures/` 带说明，谁都不知道 fixture 是干嘛的那天就是债务到期那天。
11. **01/02 开工时明确模块边界。** 新表进 config 文件、引擎函数尽量独立文件——
    别继续往七千行的 `tools.js` 里堆。
