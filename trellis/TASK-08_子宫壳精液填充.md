## 核心生理模型

```
宫壁（容器）
  ↓
宫腔间隙 ←—— 精液积蓄在这里（孕期/临产期）
  ↓
羊膜（气球/膜）—— 精液不穿透，除非破水
  ↓
羊水 + 胎儿
```

**关键原则**：孕期宫颈封闭，精液进入宫腔但**被挡在羊膜外**，在**宫颈内口上方**形成积蓄池。

---

## 分阶段液体表现

| 状态 | 孕周/descent | 宫颈状态 | 精液位置 | 液面/范围 | 与羊膜关系 |
|---|---|---|---|---|---|
| 非孕期 | days=0 | 开放 | 宫腔整体 | 从宫底往下填 | 无羊膜 |
| 孕早期 | 1-84d | **封闭** | **宫颈内口上方、羊膜外** | 小池，局限宫颈区域 | 羊膜外，不混合 |
| 孕中期 | 85-189d | **封闭** | 同上 | 同上 | 羊膜外，不混合 |
| 孕晚期 | 190-252d | **封闭** | 同上 | 同上 | 羊膜外，不混合 |
| **临产期** | **253-280d** | 软化/微张 | 同上，但**液面更高、范围更大** | 向宫底方向蔓延 | 仍在羊膜外 |
| 逾期 | >280d | 更成熟 | 同上，更多 | 更大范围 | 仍在羊膜外 |
| 产程中 | descent>40 | 扩张 | **跟随胎儿往下进入产道** | 被胎儿推挤向下 | 仍在羊膜外 |
| **破水后** | 任意+ruptured | 扩张+膜破 | **进入羊膜内，与羊水混合** | 羊膜内液面上升 | **穿透羊膜，混合** |

## demo5 落地方案

### 新增状态

```javascript
S.semen = 0;              // 0~150 ml（当前显示量，用于动画）
S.semenTarget = 0;        // 目标量（滑块设定）
S.semenRegion = 'cervix'; // 'cervix' | 'uterus' | 'amnion' | 'canal'
```

### 区域判断逻辑

```javascript
function getSemenRegion(days, descent, ruptured) {
  if (days === 0) return 'uterus';           // 非孕期：宫腔整体
  if (ruptured) return 'amnion';             // 破水：进入羊膜
  if (descent > 40) return 'canal';          // 产程：跟随胎儿入产道
  if (days >= 253) return 'cervix_high';     // 临产/逾期：高位宫颈池
  return 'cervix';                           // 孕期：低位宫颈池
}
```

### SVG 结构与 clip

| 区域 | clip-path | 说明 |
|---|---|---|
| 宫腔整体（非孕） | `url(#cavityClipId)` | 只 clip 宫腔 |
| 宫颈池（孕期） | `url(#cervixPoolClip)` | **新建**：宫颈内口上方小区域 |
| 宫颈池高位（临产） | `url(#cervixPoolClipHigh)` | **新建**：更大范围，向宫底蔓延 |
| 产道（产程） | `url(#canalClipId)` | 只 clip 产道 |
| 羊膜内（破水） | `url(#amnionClipId)` | **新建**：羊膜内部 |

⚠️ **注意 v6 那条口径**：`cavityClipId` 被胎盘/胎儿/羊膜三处共用，
`contentClipId` 才是宫腔 ∪ 管腔的并集。**羊膜绝不能用并集那个** ——
羊膜是沿 clip 内的腔 path 描边，用并集会顺着管腔也描一圈。

### 液体形状

- **宫颈池**：梯形/半月形，底部在宫颈内口，顶部波浪液面（振幅小 2-3px）
- **宫腔/羊膜内**：类椭圆，波浪液面（振幅大 6-10px，参考巴斯特）
- **产道**：圆柱形，跟随管腔宽度

### 注入动画

- 触发时从当前量 `S.semen` 涨到 `S.semenTarget`（rAF 驱动，easeOutCubic，~800ms）
- 液面波浪可以有**微波动画**（相位偏移，2-3s 周期循环）

### 产程跟随

descent 增加时，宫颈池液体**被胎儿推挤**，从宫颈区域流向产道。
表现为：宫颈池液面下降 ＋ 产道液面上升。

### z 序（从下到上）

```
1. 宫壁（myometrium）
2. 精液层（cervix/uterus/canal/amnion 根据状态）
3. 羊膜（membrane）
4. 胎儿（fetus-slot）
5. 插入物（insert-slot）
```

## 验收标准

1. `semen=0` 时无任何液体痕迹
2. **非孕期**：液体从宫底往下填，波浪液面
3. **孕期（未临产）**：液体局限在**宫颈内口上方小池**，不接触羊膜
4. **临产期**：宫颈池**液面更高、范围更大**，向宫底蔓延
5. **产程（descent>40）**：液体**跟随胎儿进入产道**，宫颈池排空
6. **破水后**：液体**进入羊膜内**，与羊水混合，羊膜内液面上升
7. 注入动画流畅，液面停在正确高度
8. 与胎儿、插入物同屏时遮挡关系正确（精液在胎儿/羊膜之下，宫壁之上）
9. 液面波浪与腔壁贴合、不越出对应 clip

⚠️ **判据是看图，不是自造指标。** 上面九条里 2–6 都是观感问题，
数值证明不了，必须出图目视确认。
